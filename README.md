# 群聊 AI 助手

把一个 QQ 小号变成群里的 AI 群友 —— 被 @ 会回，平时会接话，还记得住你们聊过什么。

![配置控制台](docs/images/console.png)

不用服务器、不用命令行的思路：**双击两个 bat，跟着页面走一遍，它就能在群里说话。**

---

## 30 秒上手（Windows）

1. 去 [Releases](https://github.com/bzq1234qwer-debug/group-ai-bot/releases/latest) 下载 `group-ai-bot-v*.zip`
2. 解压，双击 **`准备运行环境.bat`**（自动下载 Node，约 30MB，等它自己关掉）
3. 双击 **`启动.bat`**，浏览器会自动打开配置页
4. 跟着页面上的「上手向导」走完 5 步

### 你需要准备三样东西

| 东西 | 说明 |
|---|---|
| **一个 QQ 小号** | 机器人就是这个号。强烈建议不要用主号 |
| **一个 DeepSeek API Key** | [platform.deepseek.com](https://platform.deepseek.com) 注册，充 10 块能用很久 |
| **手机** | 第 ③ 步要扫码登录 QQ |

第一次配置大约 **15 分钟**，大部分时间在下载。

> 详细图文说明在压缩包里的 **`使用说明.txt`**。

## 它能做什么

| 能力 | 说明 |
|---|---|
| **被 @ 必回** | 点名就答，不受概率影响 |
| **自己判断要不要插话** | 闲聊时它会接话，冷场时保持安静；也可以切成"只在被 @ 时说话" |
| **主动开口** | 群里安静久了，会自己冒一句（可关） |
| **四层记忆** | 最近 60 条原话 → 滚动摘要 → 结构化事实（谁喜欢什么、约定了什么）→ 全文检索旧对话 |
| **每日归档** | 每天自动把群聊和私聊写成 Markdown，按会话分文件夹，可选打 zip |
| **认真模式** | 被 @ 的技术问题会开思考，答得更细（会更慢，可关） |
| **花钱上限** | 可设每天最多花多少，到顶就自己停 |
| **内容安全** | 入口和出口都过一遍词表，越界就不接这个话题 |
| **语音**（可选） | `/语音 你好` 发一条语音；需要额外装 Python |

支持多个号、多个群。数据全部存在本机 `data\` 里，不上传。

## 它是怎么工作的

```
QQ ←→ NapCat（注入 QQ 客户端，提供 OneBot 接口）
         ↕
     运行时（Node 24，零运行时依赖）
       ├─ 触发判断：被 @ / 问句 / 命中话题 / 正在聊天 → 决定要不要开口
       ├─ 记忆：窗口 + 摘要 + 事实 + 全文索引
       ├─ 去"AI 味"：剥掉 Markdown、模仿的前缀、过长句子
       └─ 归档：每天写成 Markdown
         ↕
     DeepSeek API（用户自己的 Key）
```

**不托管、不代收费用。** 服务器、账号、Key 都是用户自己的。

也支持 Docker 部署到自己的服务器，见 [`docs/server.md`](docs/server.md)。

## 常见问题

**关掉电脑它会掉线吗？**
会。它跑在你自己电脑上。

**会被封号吗？**
有可能。它通过非官方接口接入 QQ，和使用同类工具的风险一样。**用小号。**

**要一直开着吗？**
是的。想开机自启，双击一次 `开机自启.bat`。

**花了多少钱？**
实测一个群聊一整天大约 ¥0.05（`deepseek-flash`）。控制台里能看到每天的花费。

**能不用 DeepSeek 吗？**
目前只对接了 DeepSeek 的 OpenAI 兼容接口，换 baseUrl 理论上可以，没测过。

**语音为什么发不出来？**
语音需要本机有 Python + `edge-tts`。不装也不影响聊天。
